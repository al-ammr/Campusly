# Components Directory

- `components/ui/`: Atomic base design system components (buttons, badges, inputs, dialogs)
- `components/shell/`: Global navigation shell, top bar, bottom floating tab bar, footer
- `components/listing/`: Community, event, and opportunity cards and views
- `components/spotlight/`: Paid showcase cards and submission forms
- `components/admin/`: Moderation console tables, review queues, and metrics charts
